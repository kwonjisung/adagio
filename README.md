# Adagio — 지금, 이 순간의 클래식

시간·날씨·기분·활동에 맞는 클래식을 추천하고, 곡 정보·감상 포인트·상식을 보여주며 들려주는 웹사이트입니다.

- 22가지 순간(시간 4 · 날씨 4 · 기분 4 · 활동 10)마다 한 곡씩 추천
- 3D 턴테이블: 재생하면 음반이 돌고 바늘이 내려오며, 곡을 바꾸면 음반을 갈아 끼우는 모션
- 재생 중 지금 흐르는 구간의 감상 포인트 표시
- 모바일: 재생 중 화면 꺼짐 방지(Wake Lock), 잠금화면 컨트롤(Media Session)

정적 파일만으로 동작합니다. `index.html`을 GitHub Pages 등으로 그대로 배포하면 됩니다.
